# 承認ルート確認事項

## MVP内で確認が必要

### 1. 他社AA・書類OK前出品
- 承認フロー一覧では承認者が空欄。
- 連動仕様では「森重副本部長」と記載。
- 現行ルールとして森重副本部長固定でよいか確認する。

### 2. 自社AA・月末書類OK前出品
- 「森重・高口」の意味を確認する。
- 候補:
  1. 森重 → 高口の直列承認
  2. 2名全員の承認
  3. どちらか1名の承認

### 3. 副本部長承認
以下のカテゴリで承認者の決定方法を確認する。
- 赤字案件の事前買取申請
- 賛助会費・会合参加・出店祝い等の支出
- はなまる理由書利用

候補:
- 4名から申請者が選択
- 支店・ブロックにより自動決定
- 固定担当者

### 4. 法人営業の食事会経費
「木下・武内 経由で会長承認」の順序を確認する。

候補:
- 木下 → 武内 → 会長
- 木下または武内 → 会長
- 木下と武内の全員承認 → 会長

### 5. 修理承認
「リペア事業部」をSalesforce上で何として扱うか確認する。

候補:
- 固定User
- Queue
- Public Group
- 事業部内の申請担当者

### 6. その他承認申請
- 第1承認者を自由選択可能にするか
- 選択可能な役職・ユーザーを制限するか
- 最大4段階まで申請者が設定可能にするか
